# Тестовое покрытие: Game Currency Shop

Тестируется `index.html`. Бэкенд подменяется моками (`page.route`), поэтому тесты запускаются без сервера.
Запуск: `npm install`, `npx playwright install chromium`, `npm test`.

## 1. Покрытие требований

Тестовое покрытие = (требования, покрытые тест-кейсами / все требования) × 100%

| № | Требование | Тест-кейсы (`tests/shop.spec.js`) |
|---|---|---|
| R1 | Регистрация создаёт аккаунт по логину и паролю | TC1 |
| R2 | Вход с верными данными открывает каталог; сохранённый токен пропускает форму; просроченный токен возвращает на вход | TC2, TC2b, TC2c, TC2d |
| R3 | При неверных данных ошибка показывается в `#err` | TC3, TC3b |
| R4 | Поиск фильтрует каталог по названию, названия экранируются | TC4, TC4b |
| R5 | Клик по чипу игры ставит фильтр, повторный клик снимает | TC5 |
| R6 | «В корзину» добавляет товар, повтор увеличивает количество (максимум 99) | TC6, TC7 |
| R7 | Пополнение Steam принимает сумму от $1 до $1000 | TC8 (0, 1, 1000, 1001), TC8b |
| R8 | «Перейти к оплате» неактивна при пустой корзине | TC9 |
| R9 | Оплата: способ, 5-секундный таймер, создание заказа; отказ банка; истёкшая сессия | TC10, TC10b, TC10c, TC10d, TC10e |

| R12 | Смена пароля | TC13, TC13b |
| R13 | Выход из аккаунта очищает сессию и корзину | TC14 |

Покрыто 13 из 13: **13/13 × 100% = 100%**.

Замечание: поле Steam имеет `step="1"`, но обработчик проверяет только диапазон, поэтому дробная сумма (например `1.5`) попадает в корзину (TC8b фиксирует это поведение).

Тестовое покрытие = (выполненные строки / все строки) × 100%

Покрытие снимается через Chrome DevTools Protocol (то же, что вкладка Coverage в DevTools), отчёт пишется в `coverage/code-coverage.md` после каждого `npm test`.

Результат прогона (34 теста, все пройдены):

- символов кода выполнено: 8571/8571 = **100%**

Первый прогон набора TC1–TC14 без дополнительных проверок давал 99.3% символов и 97.7% строк. Не выполнялись переключение вкладки обратно на «Вход», клик мимо кнопки в каталоге, ошибка `/api/me` после оплаты и ошибка `/api/me` при открытии профиля. Для них добавлены TC3, TC4, TC10e, TC12c, TC12d.

## 3. Control Flow Graph: `$('#cartList').onclick`

```
[1] b = closest('[data-a]')
      │
   <b пуст?> ──да──► [END]                         P1
      │нет
[2] i = cart[n]; i.qty = min(99, i.qty ± 1)
      │
   <i.qty < 1?> ──да──► [3] cart.splice(n,1) ──┐   P3
      │нет                                      │
      └────────────────────────────────────────►[4] drawCart() ► [END]   P2
```

Цикломатическая сложность = 2 условия + 1 = 3.

| Путь | Тест | Действие |
|---|---|---|
| P1 | T1 | клик мимо кнопок в списке корзины |
| P2 | T2 | клик «+» и «−» при количестве 2 |
| P3 | T3 | клик «−» у позиции с количеством 1 |

Покрытие путей: 3/3 = **100%**.
